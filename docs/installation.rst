============
Installation
============

You can install the package using ``pip``. Make sure you have Python 3.10 or higher installed.

.. code-block:: bash

    pip install -U yutipy

Alternatively, if you only want to use the :doc:`CLI <cli>` for searching via terminal, you can install using `pipx <https://pipx.pypa.io/stable/>`_ instead:

.. code-block:: bash

    pipx install yutipy

- After installing, ``yutipy-cli`` command will be available to run from the terminal.
